# Product captures

These images show Talweg’s `0.1.0-beta.1` source candidate using built-in examples. Screenshots are 1440 × 960. Dark/light variants are provided for the architecture, planning and math boards.

`collaboration.gif` is a short loop for Markdown. `collaboration.mp4` is an H.264 version for playback or upload to a GitHub release. Both show the same sequence: a guest selects and moves a service, edits its label and draws on the board. The recording uses two browser contexts and a local relay on one computer.

When replacing captures, keep a consistent viewport, wait for fonts and the visible UI to settle, and show the real application. Use public sample data. Never capture an invitation, credentials, private project names or personal folder paths. Keep the GIF below 5 MB; use the MP4 for longer demonstrations.

The main README uses `<picture>` to choose a screenshot for the reader’s GitHub theme. Retain descriptive alternative text when updating image links.
